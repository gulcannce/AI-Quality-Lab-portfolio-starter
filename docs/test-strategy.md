# API Test Strategy

## Objective
Validate the behavior and response contracts of the demo REST API.

## Scope
- GET /users
- GET /users/{id}
- POST /users

## Test types
- Positive testing
- Negative testing
- Invalid-input testing
- Status-code validation
- Response field validation
- Data consistency validation

## Exit criteria
- Critical happy paths pass
- Negative scenarios are documented
- Automated regression suite passes
